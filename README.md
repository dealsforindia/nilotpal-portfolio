# Nilotpal Saha — N!S Graphics Portfolio

Official commercial design portfolio for **Nilotpal Saha** (Senior Graphic Designer, Kolkata).

Live URL: [https://nis-graphics-frame.vercel.app](https://nis-graphics-frame.vercel.app)

## Highlights

- **The Print Room (`/` & `/studio`)**: Editorial layout with custom typography (Didot & Pontif), 3D interactive tilts, dynamic light simulation, and campaign case studies (Gill Travels, Image Clinic, EtuTor, DesignLogo, A.G.C. Bose College).
- **Rooftop Experience (`/rooftop`)**: Dynamic celestial sky engine matching live Kolkata time (Dawn, Morning, Day, Dusk, Night) with interactive time scrubber.
- **Optimized Assets**: Modern web-optimized WebP/JPEG assets, SVG vectors, and self-hosted high-legibility webfonts.
- **Edge Performance**: Pre-configured `vercel.json` with immutable CDN caching headers and security policies.
